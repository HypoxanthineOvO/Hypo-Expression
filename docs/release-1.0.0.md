# Hypo-Expression 1.0.0

用于中文沟通、写作和改稿的表达规范Skill，重点处理防御性声明、虚构反对观点、生硬搭配和作者身份错位。

## 三种用法

- 沟通：讨论实际问题，在聊天中交代任务结果。
- 写作：根据材料或口述观点，组织报告、新闻和文章。
- 改稿：保留有用信息与格式，处理表达问题，必要时主动查阅背景。

本版包含十条共同原则、四类文体细则、项目查证方法及分类判例。文章写作支持补充事实、例子和推理，保持作者的立场与语气。

## 安装

下载 `clear-expression-1.0.0.zip`，解压得到 `clear-expression/`。将整个文件夹放入客户端的技能目录。Codex用户可放在 `~/.agents/skills/`，然后调用 `$clear-expression`。其他具备文件读取能力的AI可以从包内 `SKILL.md` 开始读取。

使用方式和目录结构见仓库README。许可证：MIT。
