# Hypo-Expression 1.0.0

用于中文沟通、写作和改稿的表达规范 Skill，重点处理防御性声明、虚构反对观点、生硬搭配和作者身份错位。

## 使用

安装后直接说“使用 Hypo-Expression 进行……”并说明任务，也可使用短名 `hypo-exp`。三个功能共用一个入口：

- 沟通：讨论实际问题，在聊天中交代主要结果。
- 写作：根据材料或口述观点，组织报告、新闻、文章及其他文档。
- 改稿：保留有用信息和格式，处理表达问题，必要时主动查阅背景。

本版包含十条共同原则、报告/新闻/文章/论文/仓库文档细则、查证方法及分类判例。主要针对 GPT-6 和 GPT-6.1 调试，其他模型的效果测试后续补充。

## 安装

下载 `hypo-exp-1.0.0.zip`，解压得到 `hypo-exp/`，将整个目录放入客户端的技能目录。Codex 用户可放在 `~/.agents/skills/`。其他有文件读取能力的 AI 从包内 `SKILL.md` 开始读取。

2026-10-07 更新本次发布：Skill 名称由 `clear-expression` 调整为 `hypo-exp`，补充仓库文档细则并更新 README。如已安装早期包，请移除旧的 `clear-expression` 安装目录或链接，再安装 `hypo-exp`，避免同时加载两份规则。
