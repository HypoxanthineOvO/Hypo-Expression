# 评测说明

## 已进行的工作

开发阶段整理了八组真实文本，覆盖研究报告、新闻、模型评测文章、课程要求、教程大纲、项目讨论及英文论文。多轮改稿使用独立GPT-6-Sol代理，生成后由作者对照原文评价，反馈用于修订规则。

分层后进行了六项任务：写法讨论、完成汇报、报告写作、新闻改稿、课程说明改稿及论文项目查阅。每项使用新上下文，只提供该任务材料与固定Skill；生成结果原样提交作者评价。作者认为这一版较此前改善明显，随后要求继续细化报告、新闻和文章的差异。

已讨论过的样本用于回归测试，不当作未见样本的泛化结果。本文不提供由模型自行打分的排行榜。

## 可复用的评测方法

1. 固定Skill版本、任务输入及可访问材料范围。
2. 独立执行任务，不向生成模型追加历史批评或其他模型答案。
3. 保存原始输出，不由主代理先润色。
4. 将完整原文、输入材料与生成结果对应展示；涉及英文语义时提供中文和必要备注。
5. 由作者指出具体问题及适用范围，再修改规则。

封闭样本不临时增加外部信息；测试项目查阅能力时另设可检索材料范围。写作测试提供事实材料，沟通测试提供请求和必要背景，不能全部用“润色旧回复”代替。

## 读者评阅的问题

- 是否回应了实际任务，作者身份是否合适？
- 是否残留虚构反对观点、自我辩护和生硬搭配？
- 信息、条件、数字和论证作用是否保留？
- 是否擅自缩短篇幅或改变格式？
- 新增事实是否有依据？需要作者决定的问题是否在查阅后提出？
- 报告、新闻与观点文章是否采用了合适的叙述方式？

新增的口述成文细则适合继续用不同作者、主题和模型试用。公开仓库保留通用判例；私人历史会话和未发表研究不随版本分发。
