# 参考资料

规则的主要依据是维护者对实际文本的逐项修改与评价。研究阶段同时比较了下列写作规范和工具，选择适用于中文表达的原则。

| 资料 | 参考方向 |
|---|---|
| [ASD-STE100](https://www.asd-ste100.org/) | 稳定术语、明确关系、按用途表达；中文规则借鉴原则，不宣称符合完整受控英语标准 |
| [Google 风格规则](https://github.com/vale-cli/Google) | 自然语气、具体表达、减少空引导语 |
| [Microsoft 风格规则](https://github.com/vale-cli/Microsoft) | 重要信息前置、常用词与稳定术语 |
| [Vale](https://github.com/vale-cli/vale) | 按文体和范围组织可维护的规则 |
| [write-good](https://github.com/btford/write-good) | 识别含混和冗余表达 |
| [proselint](https://github.com/amperser/proselint) | 具体风格问题与适用范围 |
| [Humanizer](https://github.com/blader/humanizer) | 虚构异议、模板化表达及写作过程残留 |
| [Stop That Shit](https://github.com/lennney/stop-that-shit) | 判断限定语对读者的实际作用，处理防御性表述 |
| [avoid-ai-writing](https://github.com/conorbronsdon/avoid-ai-writing) | 保持原意与结构，避免过度改写 |
| [中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines) | 中文技术文本的标点、数字和专名一致性 |
| [EDA Paper Writing](https://github.com/loujc/eda-paper-writing) | 困难、机制与证据之间的论证关系 |

本项目用中文重新组织操作要求和判例，不随包分发上述标准原文、词典或工具规则库。各参考项目的内容与许可由其原仓库维护。
