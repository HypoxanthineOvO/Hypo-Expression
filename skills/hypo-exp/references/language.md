# 语言层

本文件收集词语、句子、段落和篇章层面的常见问题。这些写法大多本身合乎语法，人也会用；读起来有AI味，是因为它们出现在不合适的位置、替代了本该写出的具体内容，或者密集到让读者注意到写法本身。

## 判断方法

遇到一个可疑的写法，依次看三点：

1. **它在这里承载了什么。** 删掉后读者是否失去信息、关系或作者的态度。只剩姿态、不剩内容的，改写或删除。
2. **它是否符合当前文体的惯例。** 校园活动报道结尾一句“为师生理解……提供了参照”是这类稿件的常规收束；同样的句子放在技术介绍的每段末尾，就是空话。惯例见各 [文体](styles.md) 细则。
3. **同类写法是否过密。** 一篇文章里出现一次排比、一处“值得注意的是”通常没有问题；段段如此，读者就会看到模板。

改的时候按原意重写整句，不在原位换一个同义词。下文每项给出“用错时的样子”和改法，判例来自真实改稿反馈。

## 词语与搭配

**拼接出来的搭配。** 几个相近的说法各取一半拼在一起，能看懂，但少有人这样说。

- “段落能否把意思接起来” → “段落之间的衔接是否通畅”。
- “把发现、依据和行动含义说顺” → 按实际内容重写，例如“让发现、依据和建议之间的关系清楚”。“说顺”含义不明，换成另一个短词也解决不了。
- “帮大模型把话写明白”：这个组合在人写的文字里很少见。可以换成“教大模型说人话”一类惯用说法。“说明白”在其他语境中照常可用，问题在这个组合。
- 结构助词按需要写完整：“让人顺畅读懂” → “让人顺畅地读懂”。

**英文语序。** 修饰语按英文习惯前置成长定语。“高调用量客户” → “调用量高的客户”；“一个基于……的、面向……的、能够……的系统” → 拆成几个短句。

**文雅动词、抽象词与戏剧化短语。** “勾勒出一条线索”“物本身的质地被悬置”“拥有自身逻辑的在场者”“寻找物的回声”“赋能”“闭环”“底层逻辑”，或在普通讨论里泛用统计与分析术语（如动辄“把问题收敛”“统一口径”），以及用刻意制造冲突感和戏剧张力的口语断言代替具体分析（如“往深了拆”“切得很狠”“把情绪接住”）。这些词让句子显得深刻或犀利，实际动作和判断却模糊了。改成说清动作的平实说法：“勾勒出一条……线索” → “进行了归纳”；“赋能” → “让……能够……”。讲座、论文或专业领域本身使用的术语照常保留，问题在写作者自己添加的姿态。

**空动词。** “进行讨论”“开展工作”“做出决定” → “讨论”“做了……”“决定”。正式公文里的固定说法（如“进行审议”）可以保留。

**无必要的比喻。** 技术介绍里的“读者会被松散的段落绊住”“句子绕远路”，比喻没有增加解释内容，直接写“读者会因此感到困扰”。比喻帮助读者理解某个具体关系时保留；文学和个人文章的修辞按作者意图处理。

## 句子

**虚构的反对观点。** “这里说的清楚，并不是要求所有文字都变短，也不是把专业内容改成浅白口号。”上下文里没人提出过这些理解，作者却先逐一否定。直接写实际含义：“这里的清楚，指文本符合它的定位，表述清晰，可读性好。”中文里的先否后肯语气较重，被否定的对象应当是前文确实出现、并且容易误导读者的理解。

**连续否定代替定义。** 用“不是A，也不是B，更不是C”来界定概念。改为正面说明它是什么，必要时补一个例子。

**语气过重的对照。** 确实要做区分，但原句的纠错力度超过了上下文的需要。“散文写物并非单纯记录形状与用途，而是……”可以改成“散文写物不一定仅仅记录物的形状与用途，也能够……”，保留区分，降低语气。

**防御性尾句。** 句末或段末追加“但这并不意味着……”“仍需进一步验证”“以官方为准”。真实限制写在相关事实旁边，说明具体影响；只为显得稳妥的尾句删除。见 [核心原则](principles.md) 第2条。

**判断腔。** 每段末尾用“本质上”“归根结底”“核心在于”接一个大词。保留确有推理支撑的结论，其余删掉或改成具体判断。

**并列和排比过剩。** “既……又……”“不仅……更……”、三项并列在每句出现。只在确有并列或递进关系时使用。

**翻译腔。** “在……的背景下”“这是一个关于……的问题”“正是由于……才使得……”、能用主动句时用被动句。先断句，再按中文语序重组，补出动作的发出者。

## 段落与篇章

**过渡套话。** “值得注意的是”“不难发现”“总而言之”“由此可见”“下面我们来看”。删掉后句子仍然成立的，就删掉；需要衔接时写出实际关系，例如前一项结果为什么引出下一项实验。

**宣布结构。** “下面不逐题播报，而是挑几组……”“本文将从三个方面展开”。直接开始写第一组内容。

**段尾总结和升华。** 每段末尾重复本段观点，或文末用“具有重要意义”“开启新篇章”收束。文末是否需要一句评价，看文体惯例；论述文章停在作者想停的地方即可，报道的结果本身也可以结束文章。

**过度解读。** 写作者替原作者或讲者补出更深的引申，例如把讲者的一句批评扩成“阻断了更丰富、更细微的书写可能”。报道和转述只写对方实际表达的意思；作者自己的判断放在评论或观点文章里，并标明是作者的判断。

**格式模板。** 每段都是“主题句加三个支撑点再加总结”，每节都用同一种开头。按内容需要安排长短段落和展开方式。

## 作者与读者的位置

作者可以解释复杂的事，也可以强烈评价、调侃、反问和使用比喻。好的表达把事情、依据、推理或作者自己的反应交给读者；作者不需要反复宣布读者应该注意什么、能收获什么，或由作者来纠正读者的什么误解。

- **阅读指挥和说教。** “你需要记住的是”“希望读者带走的是”，或用“这样写很漂亮”“读起来会很舒服”做居高临下的感受式点评。直接写要说的内容和具体理由。
- **假想反方与预设误解。** 认为一句话在回应误解，应能指出前文的说法或出处；只凭“可能有人会这样想”不够，也不用“很多人会误以为”“这是常见的误解”无依据地假定读者普遍误解来反衬随后的解释。
- **空泛升华。** 材料不足以支持更大的判断时，缩小判断的范围，不把信息不足包装成更深刻的问题。

可以放心保留的写法：作者原来的预期、现在看到的结果、改变想法的依据；有来由的疑惑、失望、惊讶和偏好；补全读者缺失一步的解释；确实需要回答的反问；让具体关系更容易理解的比喻。

改稿时也记下原文里写得好的段落，避免把自然的文字改成同一种腔调。

## 正式与自然分开判断

“为了更好地实现信息传达方面的有效提升，我们有必要对相关表述进行优化”与“我们需要修改这段话，让读者更容易理解”，前者偏书面，后者像口头汇报，两种语体没有优劣之分，不能拿来说明去AI味的效果。选判例时，应选含混搭配、翻译腔、连续否定、虚构反对观点、无用自辩这类确实有问题的写法，并保持前后场景一致。
