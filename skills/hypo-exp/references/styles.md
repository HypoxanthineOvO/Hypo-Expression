# 文体索引

只读当前任务相关的文件；多个文体并存时分别处理。

| 文体 | 细则 |
|---|---|
| 科研论文、研究段落 | [论文](styles/papers.md) |
| 研究报告、项目文档、课程要求及操作说明 | [报告与说明](styles/reports.md) |
| 新闻报道、新闻汇编 | [新闻](styles/news.md) |
| 观点文章、口述成文、个人文章、介绍与文案 | [文章与作者表达](styles/articles.md) |
| README、版本说明、提交信息及仓库配套文档 | [仓库文档](styles/repository/index.md) |

文体细则补充共用原则，用户对当前文本的明确要求优先。具体新闻格式和论文习惯不扩大为所有文本的要求。
