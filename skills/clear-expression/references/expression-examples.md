# 表达对照索引

这些判例根据用户对介绍文和真实文本改稿的逐项评价整理，公开版本采用通用场景，省略项目名称与研究细节。按当前问题读取对应文件，保留每项判断的语境与范围；不要将局部反馈变成全部文体的禁令或机械替换表。

| 当前问题 | 判例 |
|---|---|
| 生硬搭配、假靶子、否定语气、无必要比喻、正式程度 | [搭配、语气与修辞](examples/language.md) |
| 作者身份、草案及制作过程说明、分节、步骤与提醒者身份 | [身份与呈现方式](examples/identity-and-presentation.md) |
| 内部检查、来源展示、新闻信息、篇幅格式、论文论证与查证 | [信息保留、报告与科研](examples/information-and-research.md) |

用户对某个片段的认可只覆盖该片段及其具体改动，不代表整篇文章通过。历史后期稿保留比较价值，不作为完美参考答案。
